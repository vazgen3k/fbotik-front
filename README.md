# FBOтик Front

React/Vite-интерфейс для подготовки отгрузок и работы с заявками OZON.

## Локальный запуск

Сначала запустите `fbotik-back` на `http://127.0.0.1:8787`, затем:

```bash
npm install
npm run dev
```

Интерфейс откроется на `http://127.0.0.1:5173`. Vite проксирует запросы
`/local-api` на локальный backend. Для production эти маршруты также должны
проксироваться на `fbotik-back` через reverse proxy.

После загрузки Excel интерфейс группирует выбранные SKU по всем направлениям.
Массовая отправка использует основной ПВЗ `МОСКВА_10097`, ищет первое свободное
окно начиная через семь дней и показывает ход серверной очереди. Статусы созданных
`order_id` обновляются из OZON автоматически раз в минуту и вручную по кнопке.
